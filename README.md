# Miniature Diorama

Combined source for the ESP32 miniature and its Flutter Android controller.

- `masterminiature/`: master ESP32 sketch, documentation, and tests.
- `slaveminiature/`: slave ESP32 sketch.
- `dioramaapp/`: Flutter Android application.

See each project README for setup. Keep both firmware sketches in their named folders.

This repository starts with a snapshot of the local working files. Original repositories and their histories are preserved at their original locations.
